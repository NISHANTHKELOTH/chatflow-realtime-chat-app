# ChatFlow

ChatFlow is a real-time chat application built using the MERN stack. It allows users to create an account, log in securely, and chat with other users instantly. This project was built to learn full-stack development, authentication, and real-time communication.

## Live Demo

https://chatflow-realtime-chat-app.vercel.app

## Features

- User authentication
- Real-time messaging
- Online and offline status
- Profile picture upload
- Responsive user interface

## Tech Stack

### Frontend
- React
- Tailwind CSS
- Zustand

### Backend
- Node.js
- Express.js
- MongoDB
- Socket.IO
- JWT

## Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/chatflow.git
```

### Go to the project folder

```bash
cd chatflow
```

### Install dependencies

```bash
npm install
cd frontend
npm install
```

### Create a `.env` file

Add your MongoDB URI, JWT secret, Cloudinary credentials, and other required environment variables.

### Run the backend

```bash
npm run server
```

### Run the frontend

```bash
cd frontend
npm run dev
```
